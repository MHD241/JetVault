Scottish.aero V7.4 — Photo Rules + Shared Crew Moderation

WHAT'S NEW
- New public rules.html with the Scottish.aero photo submission standards.
- Submission page links directly to the full rules.
- Creator Studio now gives the Moderation tab to all Scottish.aero crew:
  Mohammed, Ellis and Arran.
- Every pending photo has an 8-point checklist.
- Approve stays disabled until all eight checks are ticked.
- Reject requires a category and a useful note for the photographer.
- Crew can also see and resolve community reports.
- Manager-only controls such as Featured status remain manager-only.

BACKEND
The required Supabase permissions and trigger changes have already been applied.
You do NOT need to run SQL or change Supabase settings.

UPLOAD
Unzip this package and upload everything inside to the repository root.
Replace account.html and admin.html, then add:
- rules.html
- assets/css/styles-v7-4.css
- assets/js/admin-v7-4.js

assets/js/config.js is NOT included and must remain untouched.
